# Citizen query router

Agent plugin that routes citizen questions to the right agency's assistant over A2A.

## Overview

A plugin for agent platforms that recognizes which agency a question belongs to and hands it over through the A2A protocol, keeping the conversation history.

## Interfaces

Protocol: `a2a`. Languages: en, tl.
